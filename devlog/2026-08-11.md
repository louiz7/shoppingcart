# Devlog — 2026-08-11

All changes in this cycle are driven by louiz7. The admin area gained new capabilities and safeguards: configuring the email add-on, enabling organization creation, and introducing an organization usage dashboard with restricted cross-tenant data and ongoing billing history.

On the data import and campaigns Front, we simplified CSV handling and extended the import format. This included removing a duplicate reference date during campaign imports, while keeping the due date as the single source, and adding support for optional file references, reference dates, and notes to keep legacy imports compatible. An accompanying email service entry was introduced to support these changes.

There are supportive UI and runtime improvements: tracking minute allowances by effective month for billing stability, resuming an interrupted agent greeting, and enabling rate-limit exemptions for widgets. Several related admin routes and components were updated to reflect these changes.
